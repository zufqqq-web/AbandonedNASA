## 📖 О проекте

Когда космическая миссия завершается, аппарат не возвращается домой. Он засыпает в холодных марсианских песках или в безмолвном лунном вакууме. 

**«Оставлена, но не забыта»** — это мультимедийный образовательный архив, созданный для **NASA Space Apps Challenge**. Проект позволяет пользователям исследовать судьбу роботов-первопроходцев и пилотируемых миссий:
- Узнать, как аппараты добирались до мест посадки и какие открытия совершили;
- Увидеть точные координаты и спутниковые карты посадок на базе официальных геоданных **NASA Trek**;
- Просматривать галерею снимков с орбитальных зондов **LROC** и **HiRISE** через открытый **NASA Image and Video Library API**;
- Услышать реконструкцию последних радиосигналов аппаратов перед угасанием связи на базе Web Audio API;
- Ощутить реальную задержку радиосигнала через Deep Space Network (DSN);
- Изучить уникальные реликвии человечества, оставленные на Луне;
- Использовать проект на **русском, английском и узбекском языках** (RU / EN / UZ).

## ✨ Ключевые возможности

### 🪐 1. Интерактивный выбор миров (World Selector)
* Мгновенное переключение между **Луной** и **Марсом**.
* Сравнение планетарных условий: средние температуры, расстояние до Земли, общее число каталогизированных аппаратов и хронологический охват миссий.

### 🗺️ 2. Интерактивная карта посадок (NASA Trek Interactive Map)
* Интеграция с официальными глобальными тайловыми сервисами **NASA Trek API**:
  * **Луна**: глобальная мозаика *LRO WAC Global Mosaic* (303 ppd, USGS / NASA).
  * **Марс**: цветная рельефная карта *MGS MOLA ClrShade + Viking MDIM* (NASA / JPL).
* Высокоточные географические координаты (широта/долгота) каждого аппарата.
* Пульсирующие радарные маркеры с краткой телеметрией, центрированием карты и переходом к подробному досье.

### 🔭 3. Орбитальная фотогалерея «Вид с орбиты» (NASA Image API)
* В модальном досье на вкладке **«Где он сейчас?»** интегрирована галерея снимков высокого разрешения с орбитальных аппаратов NASA:
  * **LROC** (*Lunar Reconnaissance Orbiter*) для лунных посадочных ступеней и аппаратов;
  * **HiRISE** (*Mars Reconnaissance Orbiter*) и **MGS** для марсианских роверов и посадочных платформ;
* Фильтрация результатов по ключевым словам для отбора максимально релевантных снимков;
* Отображение подписи, официального `nasa_id`, даты съемки и прямой ссылки на оригинальную карточку в архиве NASA;
* Автоматический fallback со ссылкой на научный каталог **NASA Planetary Data System (PDS)** при отсутствии прямых индексных снимков.

### ⏳ 4. Хронологический таймлайн (Mission Timeline)
* Временная лента открытий от первых шагов программ «Сервейер» и «Аполлон» до современных марсоходов XXI века.
* Фильтрация событий по небесным телам и просмотр ключевых вех каждой экспедиции.

### 🔍 5. Каталог аппаратов и фильтрация (Object Explorer)
* Каталог из **14 детализированных миссий** с поиском по названию, коду миссии или географической локации.
* Фильтры по категориям техники:
  * 🚙 **Роверы** (*Opportunity, Spirit, Sojourner, Curiosity, Perseverance*)
  * 📡 **Посадочные модули** (*Viking 1, Viking 2, Surveyor 3, Mars Polar Lander, Apollo 11 LM, InSight, Phoenix*)
  * 🛞 **Лунные автомобили** (*LRV-001 Apollo 15*)
  * 🚁 **Атмосферные вертолеты** (*Ingenuity*)
  * ⚡ **Сейсмические станции** (*Apollo ALSEP*)
* Фильтры по текущему состоянию: *Замолчавшие*, *Завершённые*, *Активные*.

### 📻 6. Эмоциональное ядро: «Последний сигнал» (The Last Signal)
* **Синтезатор на базе Web Audio API**: точная звуковая реконструкция спектра несущей частоты, телеметрических бипов, нарастающего шума бури и момента обрыва связи.
* Аутентичные сценарии угасания:
  * **Opportunity**: обрыв связи во время глобальной марсианской пылевой бури 2018 года.
  * **Spirit**: постепенный дрейф частоты передатчика из-за критического замерзания электроники.
  * **InSight**: плавное падение напряжения аккумуляторов, засыпанных пылью солнечных батарей, и финальный щелчок реле.
  * **Apollo 17 ALSEP**: отключение научной станции по штатной команде с Земли в 1977 году.
  * **Ingenuity**: прощальный контрольный радиопинг после повреждения лопасти на 72-м полете.
* **Canvas Oscilloscope & Spectrum Analyzer**: визуализация звуковой волны и спектра радиочастот в реальном времени.

### 📡 7. Симулятор радиозадержки DSN (Deep Space Network Simulator)
* Моделирование скорости распространения электромагнитных волн в вакууме.
* Расчет реальной задержки в одну и в обе стороны (Round-Trip Time):
  * **Земля — Луна**: ~1.28 секунды.
  * **Земля — Марс**: от 3.1 до 22.2 минут (в зависимости от положения планет на орбитах).
* Интерактивная отправка радиопакетов с визуализацией луча DSN между Землей и Марсом на базе единого источника правды с анимацией `requestAnimationFrame`.

### 🌕 8. Специальный раздел: «Что осталось на Луне» (Moon Artifacts)
* Уникальная летопись рукотворных объектов, оставшихся на лунной поверхности:
  * Лазерные уголковые отражатели (LRRR), работающие по сей день;
  * Лунные автомобили Lunar Roving Vehicle (LRV);
  * Мемориальная алюминиевая статуэтка «Павший астронавт» (*Fallen Astronaut*);
  * Кремниевые пластины доброй воли с посланиями лидеров 73 стран мира;
  * Семейная фотография астронавта Чарльза Дьюка (Аполлон-16) и мячи для гольфа Алана Шепарда (Аполлон-14).

### 📐 9. Интерактивные схемы подсистем (Schematic Subsystem View)
* Векторные схемы конструкций аппаратов (ровер, посадочный модуль, вертолет, станция).
* Интерактивная подсветка ключевых систем: РИТЭГ и солнечные панели, мачты камер, манипуляторы, научные датчики и антенны дальней космической связи.

### 🧠 10. Викторина исследователя (Space Exploration Quiz)
* Интерактивный тест из космических вопросов с мгновенной проверкой, детальными историческими комментариями и итоговым рейтингом исследователя.

### 📋 11. Полноэкранное модальное досье миссии (Mission Modal)
* Рендеринг через **React Portal** в `document.body` с блокировкой прокрутки фона;
* Закрепленная шапка с быстрым доступом к закрытию (ESC / клик вне окна);
* Вкладки:
  1. **Обзор & Схема**: общая справка, интерактивная схема систем, таймлайн вех, адаптивные карточки параметров;
  2. **Посадочный профиль**: схема входа в атмосферу, спуск, парашюты, амортизаторы / подушки / Sky Crane;
  3. **Научный вклад**: открытия, геология, атмосфера, биологические тесты;
  4. **Последний сигнал**: детальная хроника завершения работы, расшифровка финальной телеметрии;
  5. **Текущее состояние**: координаты, ориентиры, фотоархив NASA, галерея «Вид с орбиты», прямые ссылки на первоисточники NASA/JPL;
  6. **Спецификация**: стартовая масса, габариты, энергетика, бортовой вычислитель, научные приборы.

## 🐳 Запуск через Docker

В проекте настроен оптимизированный двухстадийный (`multi-stage`) Dockerfile на базе безопасного непривилегированного образа **`nginxinc/nginx-unprivileged:alpine`**, работающего на порту **`8080`**.

### 1. Сборка Docker-образа
В корневой папке проекта выполните команду сборки:
```bash
docker build -t forgotten .
```

### 2. Запуск контейнера
Запустите собранный контейнер с пробросом порта `8080`:
```bash
docker run -d --name forgotten-app -p 8080:8080 --restart unless-stopped forgotten
```

После старта приложение доступно в браузере по адресу:
👉 **[http://localhost:8080](http://localhost:8080)**

### 3. Остановка контейнера
```bash
docker stop forgotten-app
docker rm forgotten-app
```

### 4. Запуск через Docker Compose (опционально)
При необходимости можно использовать `docker-compose.yml`:
```yaml
version: '3.8'

services:
  forgotten:
    build: .
    container_name: forgotten-app
    ports:
      - "8080:8080"
    restart: unless-stopped
```
Запуск одной командой:
```bash
docker compose up -d
```

## 💻 Локальный запуск без Docker (Node.js)

### Предварительные требования
* [Node.js](https://nodejs.org/) версии **18.0** или выше (или [Bun](https://bun.sh/))
* Менеджер пакетов `npm`, `pnpm` или `bun`

### 1. Клонирование репозитория
```bash
git clone https://github.com/zufqqq-web/AbandonedNASA.git
cd AbandonedNASA
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере: **`http://localhost:3000`**

### 4. Сборка для продакшена
```bash
npm run build
```
Готовая статическая сборка будет сгенерирована в директории `dist/`. Для локального предпросмотра собранного проекта:
```bash
npm run preview
```

## 🛰️ Источники данных и открытые архивы NASA

В проекте использованы открытые данные и официальные научные архивы:
1. **[NASA Trek Global Tile Services](https://trek.nasa.gov/)** — картографические тайлы аппаратов *Lunar Reconnaissance Orbiter (LRO)* и *Mars Global Surveyor (MGS)*.
2. **[NASA Image and Video Library](https://images.nasa.gov/)** — открытый медиаархив орбитальных и поверхностных снимков NASA.
3. **[NASA Planetary Data System (PDS)](https://pds.nasa.gov/)** — телеметрия, хроники посадок и архивы научных данных.
4. **[NASA Jet Propulsion Laboratory (JPL)](https://www.jpl.nasa.gov/)** — хроника миссий Viking, Spirit, Opportunity, Curiosity, Perseverance, InSight и вертолета Ingenuity.
5. **[NASA History Division & Apollo Lunar Surface Journal](https://www.hq.nasa.gov/alsj/)** — архив миссий программы «Аполлон», лунных автомобилей LRV, зондов Surveyor и научных станций ALSEP.
