## 📖 О проекте

Когда космическая миссия завершается, аппарат не возвращается домой. Он засыпает в холодных марсианских песках или в безмолвном лунном вакууме. 

**«Оставлена, но не забыта»** — это мультимедийный образовательный архив, созданный в рамках **NASA Space Apps Challenge**. Проект позволяет пользователям исследовать судьбу роботов-первопроходцев и пилотируемых миссий:
- Узнать, как аппараты добирались до мест посадки и какие открытия совершили;
- Увидеть точные координаты и спутниковые карты посадок на базе официальных геоданных NASA;
- Услышать реконструкцию последних радиосигналов аппаратов перед угасанием связи;
- Ощутить реальную задержку радиосигнала через Deep Space Network;
- Изучить уникальные реликвии человечества, оставленные на Луне.

## ✨ Ключевые возможности

### 🪐 1. Интерактивный выбор миров (World Selector)
* Мгновенное переключение между **Луной** и **Марсом**.
* Сравнение планетарных условий: средние температуры, расстояние до Земли, общее число каталогизированных аппаратов и хронологический охват миссий.

### 🗺️ 2. Интерактивная карта посадок (NASA Trek Interactive Map)
* Интеграция с официальными глобальными тайловыми сервисами **NASA Trek API**:
  * **Луна**: глобальная мозаика *LRO WAC Global Mosaic* (303 ppd, USGS / NASA).
  * **Марс**: цветная рельефная карта *MGS MOLA ClrShade + Viking MDIM* (NASA / JPL).
* Высокоточные географические координаты (широта/долгота) каждого аппарата.
* Интерактивные маркеры с краткой телеметрией, центрированием карты и переходом к подробному досье.

### ⏳ 3. Хронологический таймлайн (Mission Timeline)
* Временная лента открытий от первых шагов программы «Аполлон» до современных марсоходов XXI века.
* Фильтрация событий по небесным телам и просмотр ключевых вех каждой экспедиции.

### 🔍 4. Каталог аппаратов и фильтрация (Object Explorer)
* Каталог с поиском по названию, коду миссии или географической локации.
* Фильтры по категориям техники:
  * 🚙 **Роверы** (*Opportunity, Spirit, Sojourner, Curiosity, Perseverance*)
  * 📡 **Посадочные модули** (*Apollo 11 Lunar Module, InSight, Phoenix*)
  * 🛞 **Лунные автомобили** (*LRV-001 Apollo 15*)
  * 🚁 **Атмосферные вертолеты** (*Ingenuity*)
  * ⚡ **Сейсмические станции** (*Apollo ALSEP*)
* Фильтры по текущему состоянию: *Замолчавшие*, *Завершённые*, *Активные*.

### 📻 5. Эмоциональное ядро: «Последний сигнал» (The Last Signal)
* **Синтезатор на базе Web Audio API**: точная звуковая реконструкция спектра несущей частоты, телеметрических бипов, нарастающего шума бури и момента обрыва связи.
* Аутентичные сценарии угасания:
  * **Opportunity**: обрыв связи во время глобальной марсианской пылевой бури 2018 года.
  * **Spirit**: постепенный дрейф частоты передатчика из-за критического замерзания электроники.
  * **InSight**: плавное падение напряжения аккумуляторов, засыпанных пылью солнечных батарей, и финальный щелчок реле.
  * **Apollo 17 ALSEP**: отключение научной станции по штатной команде с Земли в 1977 году.
  * **Ingenuity**: прощальный контрольный радиопинг после повреждения лопасти на 72-м полете.
* **Canvas Oscilloscope & Spectrum Analyzer**: визуализация звуковой волны и спектра радиочастот в реальном времени.

### 📡 6. Симулятор радиозадержки DSN (Deep Space Network Simulator)
* Моделирование скорости распространения электромагнитных волн в вакууме.
* Расчет реальной задержки в одну и в обе стороны (Round-Trip Time):
  * **Земля — Луна**: ~1.28 секунды.
  * **Земля — Марс**: от 3.1 до 22.2 минут (в зависимости от положения планет на орбитах).
* Интерактивная отправка радиопакетов с визуализацией прохождения радиосигнала через антенные комплексы Голдстоун, Мадрид и Канберра.

### 🌕 7. Специальный раздел: «Что осталось на Луне» (Moon Artifacts)
* Уникальная летопись рукотворных объектов, оставшихся на лунной поверхности:
  * Лазерные уголковые отражатели (LRRR), работающие по сей день;
  * Лунные автомобили Lunar Roving Vehicle (LRV);
  * Мемориальная алюминиевая статуэтка «Павший астронавт» (*Fallen Astronaut*);
  * Кремниевые пластины доброй воли с посланиями лидеров 73 стран мира;
  * Семейная фотография астронавта Чарльза Дьюка (Аполлон-16) и мячи для гольфа Алана Шепарда (Аполлон-14).

### 📐 8. Интерактивные схемы подсистем (Schematic Subsystem View)
* Векторные схемы конструкций аппаратов (ровер, посадочный модуль, вертолет, станция).
* Интерактивная подсветка ключевых систем: РИТЭГ и солнечные панели, мачты камер, манипуляторы, научные датчики и антенны дальней космической связи.

### 🧠 9. Викторина исследователя (Space Exploration Quiz)
* Интерактивный тест из космических вопросов с мгновенной проверкой, детальными историческими комментариями и итоговым рейтингом исследователя.

### 📋 10. Детальное досье миссии (Mission Modal Dossier)
* Полный технический паспорт каждого аппарата:
  * Как аппарат добрался до поверхности (схема перелета, тепловой щит, парашют, Sky Crane);
  * Что открыл и какие научные задачи выполнил;
  * История последнего сеанса связи и прощальные послания ученых и инженеров;
  * Где находится сейчас и прямые ссылки на первоисточники NASA и JPL.

## 🚀 Быстрый запуск

### Предварительные требования
* [Node.js](https://nodejs.org/) версии **18.0** или выше (или [Bun](https://bun.sh/))
* Менеджер пакетов `npm`, `pnpm` или `bun`

### 1. Клонирование репозитория
```bash
git clone https://github.com/zufqqq-web/AbandonedNASA.git
cd AbandonedNASA
```

### 2. Установка зависимостей
```bash
npm install
# или если вы используете bun:
# bun install
```

### 3. Запуск сервера разработки
```bash
npm run dev
# или:
# bun dev
```
После запуска откройте в браузере: **`http://localhost:3000`**

### 4. Сборка для продакшена
```bash
npm run build
```
Готовая статическая сборка будет сгенерирована в директории `dist/`. Для предпросмотра собранного проекта выполните:
```bash
npm run preview
```

## 🛰️ Источники данных и открытые архивы NASA

В проекте использованы открытые данные и картографические сервисы:
1. **[NASA Trek Global Tile Services](https://trek.nasa.gov/)** — картографические данные аппаратов *Lunar Reconnaissance Orbiter (LRO)* и *Mars Global Surveyor (MGS)*.
2. **[NASA Planetary Data System (PDS)](https://pds.nasa.gov/)** — телеметрия, хроники посадок и архивы научных данных.
3. **[NASA Jet Propulsion Laboratory (JPL)](https://www.jpl.nasa.gov/)** — хроника миссий марсоходов Spirit, Opportunity, Curiosity, Perseverance и вертолета Ingenuity.
4. **[NASA History Division & Apollo Lunar Surface Journal](https://www.hq.nasa.gov/alsj/)** — архив миссий программы «Аполлон», лунных автомобилей LRV и приборных комплексов ALSEP.
